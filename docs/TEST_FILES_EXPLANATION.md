# 测试文件说明 (Test Files Explanation)

## 两个测试文件的区别和用途

### 1. test_dynamic_detector.py - 功能演示测试

**用途**: 展示动态检测器如何检测各种代码问题

**特点**:
- 针对 Python、Java、C++ 分别测试
- 使用包含已知问题的示例代码
- 显示详细的检测结果

**运行结果示例**:
```
============================================================
测试 Python 动态检测器
============================================================

总共发现 11 个问题

按类别统计:
  user_input: 1
  resource_management: 2
  concurrency: 1
  boundary_conditions: 2
  environment_config: 2
  dynamic_execution: 3

按严重程度统计:
  HIGH: 4
  MEDIUM: 5
  LOW: 2

详细问题列表:

user_input (1 个问题):
  1. [MEDIUM] DYN-INPUT-003: JSON 反序列化可能处理不可信数据
     文件: test.py:13

resource_management (2 个问题):
  1. [HIGH] DYN-RES-001: 文件打开未使用 with 语句，可能导致资源泄漏
     文件: test.py:21
  ...
```

**结果含义**:
- **总共发现 X 个问题**: 在测试代码中检测到的问题总数
- **按类别统计**: 每个检测类别（用户输入、资源管理等）发现的问题数量
- **按严重程度统计**: 
  - HIGH（高危）: 可能导致安全漏洞或严重错误
  - MEDIUM（中危）: 可能影响稳定性
  - LOW（低危）: 代码质量建议
- **详细问题列表**: 每个问题的具体位置、严重程度、规则ID和描述

---

### 2. validate_dynamic_detection.py - 综合验证测试

**用途**: 验证动态检测功能是否正确工作

**特点**:
- 包含 6 个独立的验证测试
- 自动判断测试通过/失败
- 提供汇总报告

**6 个验证测试**:
1. **模块导入** - 验证所有检测器类能正确导入
2. **检测类别** - 验证所有 6 个检测类别都能正常工作
3. **扫描器集成** - 验证与现有扫描器的集成
4. **严重程度** - 验证能正确分级 HIGH/MEDIUM/LOW
5. **修复建议** - 验证每个问题都有修复建议
6. **多语言支持** - 验证 Python、Java、C++ 都能检测

**运行结果示例**:

**结果含义**:
- **✅ 通过**: 该测试验证成功

- **🎉 所有测试通过**: 表示动态检测功能完全正常
- **⚠️ X 个测试失败**: 表示有功能问题需要修复

---

## 何时使用哪个测试

### 使用 test_dynamic_detector.py 当你想:
- 查看动态检测器能检测哪些具体问题
- 了解每种语言的检测能力
- 调试或开发新的检测规则

### 使用 validate_dynamic_detection.py 当你想:
- 验证功能是否正常工作（类似单元测试）
- 在修改代码后快速检查是否破坏了功能
- 自动化测试（CI/CD）

---

## 快速运行

```bash
# 演示检测能力
python test_dynamic_detector.py

# 验证功能正确性
python validate_dynamic_detection.py
```

两个测试都应该成功运行且没有错误。如果 `validate_dynamic_detection.py` 显示 "6/6 测试通过"，说明动态检测功能完全正常工作。
